# Titanic Exploratory Data Analysis Dashboard

An interactive dashboard for exploring passenger survival patterns
in the Titanic dataset using Python.

## Project Overview

This project analyzes passenger information to understand how
gender, passenger class, and age were associated with survival.

## Technologies Used

- Python
- Pandas
- NumPy
- Streamlit
- Plotly
- Seaborn
- Matplotlib

## Key Features

- Interactive passenger filters
- Passenger statistics and summary metrics
- Survival analysis by gender
- Survival analysis by passenger class
- Survival analysis by age group
- Interactive visualizations
- Key findings and analysis limitations

## Project Structure

- app.py — Dashboard application
- requirements.txt — Required Python libraries
- titanic_cleaned.csv — Cleaned dataset
- README.md — Project documentation

## Run Locally

Install the required libraries:

    pip install -r requirements.txt

Run the dashboard:

    streamlit run app.py
